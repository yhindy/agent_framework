# Keyboard Shortcuts Implementation - Engineering Design

## 1. Architecture Overview

### Design Philosophy
The keyboard shortcuts system will be implemented as a lightweight, React-based solution that:
1. Uses a custom hook (`useKeyboardShortcuts`) for reusable shortcut registration
2. Leverages React Context to expose modal controls from Dashboard to parent components
3. Maintains separation of concerns between shortcut detection and action execution
4. Supports cross-platform modifier keys (Cmd on macOS, Ctrl on Windows/Linux)

### Acceptance Criteria Mapping

| Criterion | Implementation |
|-----------|----------------|
| 1. Cmd+N opens New Minion dialog | useKeyboardShortcuts hook + modalControls.openNewMinionModal() |
| 2. Cmd+O opens Project Picker | useKeyboardShortcuts hook + modalControls.openProjectPicker() |
| 3. Cmd+↑/↓ navigates between minions | useKeyboardShortcuts hook + navigationControls.navigateTo*() |
| 4. Cmd+T opens Teleport dialog | useKeyboardShortcuts hook + modalControls.openTeleportModal() |
| 5. Escape closes modals | useKeyboardShortcuts hook + modalControls.closeCurrentModal() |
| 6. Cmd+/ shows shortcuts help | useKeyboardShortcuts hook + toggleHelpOverlay() |
| 7. Cmd+Shift+N creates Super Minion | useKeyboardShortcuts hook + modalControls.openSuperMinionModal() |
| 8. Disabled in text inputs | isInputElement() check in hook |
| 9. Visual indicators | Shortcut hints in MissionDropdown + tooltips |
| 10. Reusable hook | useKeyboardShortcuts.ts as standalone module |
| 11. Cross-platform support | Platform detection in hook with meta/ctrl switching |

## 5. API Design

### useKeyboardShortcuts Hook

```typescript
// gui/src/renderer/src/hooks/useKeyboardShortcuts.ts

import { useEffect, useCallback } from 'react'

interface ShortcutConfig {
  key: string                    // e.g., 'n', 'o', 'ArrowUp', 'Escape'
  modifiers?: {
    meta?: boolean               // Cmd on Mac, Windows key on Windows
    ctrl?: boolean
    shift?: boolean
    alt?: boolean
  }
  action: () => void
  description: string
  enabled?: boolean | (() => boolean)
}

interface UseKeyboardShortcutsOptions {
  shortcuts: ShortcutConfig[]
  enabled?: boolean
  disableWhenInputFocused?: boolean  // Default: true
}

export function useKeyboardShortcuts(options: UseKeyboardShortcutsOptions): void {
  const { shortcuts, enabled = true, disableWhenInputFocused = true } = options

  const isInputElement = useCallback((element: Element | null): boolean => {
    if (!element) return false
    const tagName = element.tagName.toLowerCase()
    if (tagName === 'input' || tagName === 'textarea' || tagName === 'select') {
      return true
    }
    // Check for contenteditable
    if (element.getAttribute('contenteditable') === 'true') {
      return true
    }
    return false
  }, [])

  const handleKeyDown = useCallback((event: KeyboardEvent) => {
    if (!enabled) return

    // Skip if focused on input element
    if (disableWhenInputFocused && isInputElement(document.activeElement)) {
      // Exception: Escape should always work to close modals
      if (event.key !== 'Escape') {
        return
      }
    }

    // Detect platform for correct modifier key
    const isMac = navigator.platform.toUpperCase().indexOf('MAC') >= 0

    for (const shortcut of shortcuts) {
      const shortcutEnabled = typeof shortcut.enabled === 'function'
        ? shortcut.enabled()
        : shortcut.enabled ?? true

      if (!shortcutEnabled) continue

      const modifiers = shortcut.modifiers ?? {}

      // Check modifier keys
      // On Mac: use metaKey (Cmd). On Windows/Linux: use ctrlKey
      const modifierMatches = isMac
        ? (modifiers.meta ?? false) === event.metaKey
        : (modifiers.meta ?? false) === event.ctrlKey

      const ctrlMatches = (modifiers.ctrl ?? false) === event.ctrlKey
      const shiftMatches = (modifiers.shift ?? false) === event.shiftKey
      const altMatches = (modifiers.alt ?? false) === event.altKey

      // Check key
      const keyMatches = event.key.toLowerCase() === shortcut.key.toLowerCase() ||
                         event.code.toLowerCase() === shortcut.key.toLowerCase()

      if (keyMatches && modifierMatches && ctrlMatches && shiftMatches && altMatches) {
        event.preventDefault()
        event.stopPropagation()
        shortcut.action()
        return
      }
    }
  }, [enabled, shortcuts, disableWhenInputFocused, isInputElement])

  useEffect(() => {
    document.addEventListener('keydown', handleKeyDown, true)
    return () => {
      document.removeEventListener('keydown', handleKeyDown, true)
    }
  }, [handleKeyDown])
}

// Helper to get platform-specific modifier symbol
export function getModifierSymbol(): string {
  const isMac = navigator.platform.toUpperCase().indexOf('MAC') >= 0
  return isMac ? '⌘' : 'Ctrl'
}

export function formatShortcut(key: string, modifiers?: { meta?: boolean; shift?: boolean }): string {
  const parts: string[] = []
  const mod = getModifierSymbol()

  if (modifiers?.meta) parts.push(mod)
  if (modifiers?.shift) parts.push('Shift')
  parts.push(key.toUpperCase())

  return parts.join('+')
}
```

### KeyboardShortcutsContext

```typescript
// gui/src/renderer/src/contexts/KeyboardShortcutsContext.tsx

import { createContext, useContext, useState, useCallback, ReactNode } from 'react'

interface ModalControls {
  openNewMinionModal: () => void
  openSuperMinionModal: () => void
  openTeleportModal: () => void
  openProjectPicker: () => void
  closeCurrentModal: () => void
  isModalOpen: boolean
}

interface NavigationControls {
  navigateToPreviousMinion: () => void
  navigateToNextMinion: () => void
  canNavigatePrevious: boolean
  canNavigateNext: boolean
}

interface KeyboardShortcutsContextType {
  // Modal controls registration
  registerModalControls: (controls: ModalControls) => void
  modalControls: ModalControls | null

  // Navigation controls registration
  registerNavigationControls: (controls: NavigationControls) => void
  navigationControls: NavigationControls | null

  // Help overlay
  showHelpOverlay: boolean
  toggleHelpOverlay: () => void
}

const KeyboardShortcutsContext = createContext<KeyboardShortcutsContextType | null>(null)

export function KeyboardShortcutsProvider({ children }: { children: ReactNode }) {
  const [modalControls, setModalControls] = useState<ModalControls | null>(null)
  const [navigationControls, setNavigationControls] = useState<NavigationControls | null>(null)
  const [showHelpOverlay, setShowHelpOverlay] = useState(false)

  const registerModalControls = useCallback((controls: ModalControls) => {
    setModalControls(controls)
  }, [])

  const registerNavigationControls = useCallback((controls: NavigationControls) => {
    setNavigationControls(controls)
  }, [])

  const toggleHelpOverlay = useCallback(() => {
    setShowHelpOverlay(prev => !prev)
  }, [])

  return (
    <KeyboardShortcutsContext.Provider value={{
      registerModalControls,
      modalControls,
      registerNavigationControls,
      navigationControls,
      showHelpOverlay,
      toggleHelpOverlay
    }}>
      {children}
    </KeyboardShortcutsContext.Provider>
  )
}

export function useKeyboardShortcutsContext() {
  const context = useContext(KeyboardShortcutsContext)
  if (!context) {
    throw new Error('useKeyboardShortcutsContext must be used within KeyboardShortcutsProvider')
  }
  return context
}
```

## 8. Risk Assessment

### Potential Issues and Mitigations

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| **Shortcut conflicts with system** | Medium | Medium | Choose non-system shortcuts. Avoid Cmd+Q, Cmd+W, Cmd+Tab. Test on both macOS and Windows. |
| **Shortcut conflicts with terminal** | High | Medium | Terminal component captures its own keystrokes via xterm.js. Verify shortcuts work when terminal is visible but not focused. |
| **Performance impact** | Low | Low | Single global event listener with early returns. Use useCallback for handlers. |
| **Memory leaks** | Low | Medium | Ensure cleanup in useEffect. Follow pattern from usePRPolling. |
| **Context not registered in time** | Medium | High | Add null checks in keyboard handler. Show user feedback if action unavailable. |
| **Modal state sync issues** | Medium | Medium | Use isModalOpen computed property. Test rapid open/close sequences. |
| **Arrow key conflicts with scrolling** | Medium | Medium | Only capture Cmd+Arrow, not plain Arrow keys. Verify scrolling still works. |
| **Agent list not populated** | Low | Medium | Handle empty list gracefully. Disable navigation shortcuts when no agents exist. |

### Edge Cases to Handle

1. **No active projects**: Cmd+N should navigate to project picker first
2. **Single agent**: Cmd+Up/Down should be no-ops (no wrap-around)
3. **Agent view not mounted**: Navigation shortcuts should work from Dashboard too
4. **Rapid modal switches**: Ensure state consistency when quickly pressing shortcuts
5. **Help overlay open**: Escape should close help, not underlying modal
6. **Nested modals**: PR confirm modal inside Dashboard - Escape should close innermost
